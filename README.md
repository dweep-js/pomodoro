# Pomo - Pomodoro Timer

A really simple Pomodoro timer website, built for personal use (mainly to stay focused while studying). Bare bones by design — no clutter, no extra features, just a timer.

**Live site:** https://dweep-js.github.io/pomodoro/

## Features

- Choose your focus minutes, then hit "Set & Start Timer"
- Play / pause / replay controls
- Relaxing air audio
- Minimal hourglass-themed UI, single page, no sign-up or backend needed

## Tech

- Static site, hosted via GitHub Pages
- Lightweight HTML/CSS/JS, no frameworks required to run

## Usage

1. Open the site
2. Pick your focus duration in minutes
3. Hit "Set & Start Timer"
4. Do any activity for as long as the timer runs
